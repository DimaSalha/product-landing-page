# Daymark Product Landing Page — Demo

A responsive fictional productivity-app landing page built with HTML and CSS for a web development portfolio.

## Features
- Responsive hero section with a CSS dashboard mockup
- Features, workflow, pricing, and FAQ sections
- Semantic HTML and SEO title/meta description
- No real signup, payment, or data collection

## Live demo
Enable GitHub Pages in **Settings → Pages**. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, and save. Once deployment finishes, the expected URL is `https://dimasalha.github.io/product-landing-page/`.

Daymark and its pricing are fictional portfolio-demo content.
